## 当前已实现

- React + TypeScript + Vite 学习空间入口与单工作台；绿色/黄色笔记风格，折叠讲解、题内作答/求助、底部讲义提问、独立草稿与历史、移动导航、键盘焦点及减少动态效果。
- FastAPI 模块化后端，SQLite WAL、编号迁移、持久化文件与请求幂等。无 Redis、独立数据库或向量服务。
- PDF/PPTX 上传、内容类型与大小检查、后台解析、章节生成、备注提取、图片/空文本提示、失败重试、重启中断识别、文件哈希复用。
- PDF.js 阅读器与章节/证据页定位；PPTX 以提取文本、页号和备注展示。多资料结构保持独立，不静默合并同名章节。
- DeepSeek Chat Completions 适配、流式传输、JSON Schema 校验、最多一次 JSON 修复、180 秒总预算、四轮有界资料检索工具。Partner 无课程工具。
- 讲解、示例、课外补充标记、LLM 核心问题计划；单选/数值规则评分、短答结构化评分、提示记录、答案隐藏、自由跳过、专项训练新计划与争议复核审计。
- 考前复习使用独立的章节思维导图和练习会话：节点摘要、来源页、选点提问/练习、弱项优先、本轮总结。通过明确按钮切换，退出恢复原学习位置；不把自然语言关键词当作模式切换命令。日常检查通过满七天仍标记待复查。
- 默认按需生成当前小节，整章后台准备改为主动开启。2.5 秒轻量状态查询、隐藏页暂停、避免重叠请求；同一讲解不随后台状态重新解析。Markdown/GFM、四种数学定界符、矩阵、多行推导；导图库按需加载。
- 作答原图绑定具体题目并本地持久化；上传、预览、转写、编辑确认、失败重试状态明确。原图直接参与正常和复习判分，无须先确认 OCR 文字；换题、空间切换不会带入其他题的图。
- 独立 Partner 陪聊、近期历史与摘要；每六条可记忆用户消息触发后台语义整理，保留来源和水位，冲突可替代，删除代际检查防止旧任务写回。课程、全局偏好和 Partner 范围独立。
- 可查看、修改、删除和暂停长期记忆；本轮私密标记阻止后续长期抽取。业务进度不由摘要覆盖。
- Windows Tk 桌面小芽、拖动、托盘、应用打开/聚焦、陪聊入口、位置保存、自己启动的后台进程退出管理。
- 两份依赖锁、原创样例生成器、自动化测试、资源测量脚本、显式启用的真实 API 冒烟脚本。

## 关键取舍和实际限制

1. 已使用本机现有 DeepSeek 配置完成三个原创小样本验证：章节讲解、选择题理由判分、答案图片转写。未上传私人讲义；这不等于八类教学质量评测全部通过。密钥不进入源码或测试，Git 提交/推送钩子检查本地配置路径及常见密钥格式。
2. 当前检索使用页级文本和中文双字/关键词评分，没有实现向量 Embedding 索引及独立 Embedding 配置。它适合小型文本资料，是显式的关键词检索实现，不能宣称具有语义检索质量。大教材需要进一步测量与索引优化。
3. 目录保留 PDF 前两级书签、父子关系及页内边界；无书签时识别正文标题并过滤重复页眉/目录页。大章作折叠容器，小节负责教学。旧空间可复用文件创建修正目录并保留旧记录。复杂排版、缺失/错误书签仍需验证；无标题时按页分组。编辑入口仍仅支持改名。
4. 每个可学习小节以一个目标和一组核心问题为检查计划，未展开完整目标树。专项训练生成新的小节核心检查计划，重点覆盖此前缺口；旧题和作答保留审计，通过状态根据最新计划计算。同章串行后台准备仅由用户主动开启，不写入用户对话、不代表用户已经学会；当前操作优先，可取消。
5. 复习导图最多 30 节点、三层节点关系；最多处理 24 小节，每小节检索两页局部证据。它是复习提纲，不是对全书所有知识点的穷尽保证。每轮最多五题，采用明确状态排序和 LLM 变式题；复习状态独立保存，不将日常通过直接等同本轮通过。未实现跨章节时间计划、推送或复习判分争议审计；日常判分复核仍保留。
6. 资料导入的 PDF 无 OCR，资料中的图片、复杂公式和图表没有视觉理解；作答图片独立接入视觉转写和直接判分，文字确认可选。原图持久化于忽略的 SQLite，仅转写/判分时发送给 DeepSeek；移除草稿附件不删除已提交证据，删除空间级联清理。文件页序号用于稳定引用，不声称识别全部印刷页码。PPTX 不还原完整幻灯片视觉。
7. 流式传输向界面发送生成阶段/接收进度；教学内容整体通过结构与引用校验后展示，不将未验证评分实时提交。引用存在性校验不等于内容支持性已被证明，需要真实质量评测。
8. 记忆压缩保留原始档案；模型整理不可用时采用有来源的短摘录。自动记忆不允许跨空间扩大范围；数据库业务事实由代码读取。尚未提供独立记忆向量索引、图谱、过期策略编辑器。
9. 本机单用户边界采用回环监听、Host/Origin 检查和自定义请求头；不具备远程登录、多租户认证或面向公网的防护部署。前端草稿存储在当前浏览器 localStorage。
10. 桌面窗口自测已执行；长期后台运行、不同缩放/多显示器、第三方浏览器前台聚焦及真实鼠标托盘交互仍需人工验收。暂未打包安装程序。

以上是已知范围差异，不能将它们计为产品文档全部条目已经完成。当前产品文档位于 [prompt.md](../prompt.md)；核心路径已可运行，其余条目保留为后续迭代目标。

### 本轮设计依据与真实调用

2026-11-25 核对 [DeepTutor 导图改动 PR #1295](https://github.com/HKUDS/DeepTutor/pull/1295/files)，借鉴限定层级、短标签和生成后校验。该改动是参考设计证据，不等于照搬已发布接口。LearNest 使用结构化 JSON + React Flow，便于节点绑定章节、原文和题目，避免执行模型产生的页面代码。

[DeepTutor v1.7.3](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.3) 的题目关联求助与作答分离思路用于区分提问和提交；前端参考 [React Flow 思维导图教程](https://reactflow.dev/learn/tutorials/mind-map-app-with-react-flow) 与 [性能指南](https://reactflow.dev/learn/advanced-use/performance)，采用稳定节点类型、记忆化组件及折叠树。仅借鉴思路，没有声称性能与上游相同。

真实验证运行 `uv run python scripts/smoke_review.py --live`，使用本地 `deepseek-flash` 和原创临时资料，未上传用户教材。生成 5 个导图节点约 3.70 秒、复习出题约 4.62 秒、仅原图判分约 2.83 秒；转写非空且未标不确定，参考答案图判为正确，原学习进度不变。时间是单次小样本含请求/保存耗时，不能推及大教材或网络较差情况。

浏览器回归发现并修复“上一题结束后界面过早允许操作新题”的竞态：完成会话刷新后才恢复提交按钮。原图替换失败时清除旧绑定，防止新预览与旧附件错配。导图控件样式隔离，避免全局按钮内边距把缩放图标挤没。
