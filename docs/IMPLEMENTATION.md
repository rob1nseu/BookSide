# 实现与验证记录

更新日期：2026-11-25。产品开发文档保留完整目标；本文区分当前已经验证的功能、默认取舍和仍需验证的能力。

## 当前已实现

- React + TypeScript + Vite 学习空间入口与单工作台；绿色/黄色笔记风格，当前任务、折叠讲解、历史、固定输入区、移动导航、键盘焦点及减少动态效果。
- FastAPI 模块化后端，SQLite WAL、编号迁移、持久化文件与请求幂等。无 Redis、独立数据库或向量服务。
- PDF/PPTX 上传、内容类型与大小检查、后台解析、章节生成、备注提取、图片/空文本提示、失败重试、重启中断识别、文件哈希复用。
- PDF.js 阅读器与章节/证据页定位；PPTX 以提取文本、页号和备注展示。多资料结构保持独立，不静默合并同名章节。
- DeepSeek Chat Completions 适配、流式传输、JSON Schema 校验、最多一次 JSON 修复、180 秒总预算、四轮有界资料检索工具。Partner 无课程工具。
- 讲解、示例、课外补充标记、LLM 核心问题计划；单选/数值规则评分、短答结构化评分、提示记录、答案隐藏、自由跳过、专项训练新计划与争议复核审计。
- 章节学习与考前复习共用证据，分开保存导航位置。自然语言「考前复习/帮我复习/进入复习」也可触发复习。通过检查满七天标记待复查。
- 独立 Partner 陪聊、近期历史与摘要；每六条可记忆用户消息触发后台语义整理，保留来源和水位，冲突可替代，删除代际检查防止旧任务写回。课程、全局偏好和 Partner 范围独立。
- 可查看、修改、删除和暂停长期记忆；本轮私密标记阻止后续长期抽取。业务进度不由摘要覆盖。
- Windows Tk 桌面小芽、拖动、托盘、应用打开/聚焦、陪聊入口、位置保存、自己启动的后台进程退出管理。
- 两份依赖锁、原创样例生成器、自动化测试、资源测量脚本、显式启用的真实 API 冒烟脚本。

## 关键取舍和实际限制

1. 已使用本机现有 DeepSeek 配置完成三个原创小样本验证：章节讲解、选择题理由判分、答案图片转写。未上传私人讲义；这不等于八类教学质量评测全部通过。密钥不进入源码或测试，Git 提交/推送钩子检查本地配置路径及常见密钥格式。
2. 当前检索使用页级文本和中文双字/关键词评分，没有实现向量 Embedding 索引及独立 Embedding 配置。它适合小型文本资料，是显式的关键词检索实现，不能宣称具有语义检索质量。大教材需要进一步测量与索引优化。
3. 目录保留 PDF 前两级书签、父子关系及页内边界；无书签时识别正文标题并过滤重复页眉/目录页。大章作折叠容器，小节负责教学。旧空间可复用文件创建修正目录并保留旧记录。复杂排版、缺失/错误书签仍需验证；无标题时按页分组。编辑入口仍仅支持改名。
4. 每个可学习小节以一个目标和一组核心问题为检查计划，未展开完整目标树。专项训练生成新的小节核心检查计划，重点覆盖此前缺口；旧题和作答保留审计，通过状态根据最新计划计算。同章串行后台准备不写入用户对话，也不代表用户已经学会；当前操作优先，可取消。
5. 考前复习排序先使用明确的学习状态规则，LLM 负责问题和讲解，尚未由 LLM 生成跨章节时间计划。未实现考试日期/可用时长表单或自动复习推送；用户无需填写这些信息才能使用复习。
6. 资料导入的 PDF 无 OCR，资料中的图片、复杂公式和图表没有视觉理解；作答图片已独立接入视觉转写，需要用户确认。文件页序号用于稳定引用，不声称识别全部印刷页码。PPTX 不还原完整幻灯片视觉。
7. 流式传输向界面发送生成阶段/接收进度；教学内容整体通过结构与引用校验后展示，不将未验证评分实时提交。引用存在性校验不等于内容支持性已被证明，需要真实质量评测。
8. 记忆压缩保留原始档案；模型整理不可用时采用有来源的短摘录。自动记忆不允许跨空间扩大范围；数据库业务事实由代码读取。尚未提供独立记忆向量索引、图谱、过期策略编辑器。
9. 本机单用户边界采用回环监听、Host/Origin 检查和自定义请求头；不具备远程登录、多租户认证或面向公网的防护部署。前端草稿存储在当前浏览器 localStorage。
10. 桌面窗口自测已执行；长期后台运行、不同缩放/多显示器、第三方浏览器前台聚焦及真实鼠标托盘交互仍需人工验收。暂未打包安装程序。

以上是已知范围差异，不能将它们计为 README 全部条目已经完成。核心路径已可运行，其余条目保留为后续迭代目标。

## 小型资源测量

`uv run python scripts/measure.py` 在临时目录运行，无模型请求。样例仅为两页中文 PDF 与一页 PPTX，不代表整本教材性能。

| 指标 | 本次测量 |
| --- | --- |
| 数据库初始化与迁移 | 24.96 ms |
| PDF 解析及本地页索引 | 60.33 ms |
| PPTX 解析及本地页索引 | 60.68 ms |
| 关键词检索均值（20 次） | 5.63 ms |
| 测量进程 RSS，开始/结束 | 60.61 / 71.76 MiB |
| 真实模型首字/完整响应 | 未测 |

资源数字为单次测量，不是 SLA，也不是服务器空闲内存。正常生产运行无需常驻 Node；可选桌面宿主额外常驻。前端主包约 239 kB（gzip 约 76 kB），PDF.js 和 Markdown/公式运行时代码按需加载。

## 设计与参考

视觉参考为 [design-concept.png](design-concept.png)。布局按「章节导航、当前任务、黄色问题区、唯一输入区、折叠辅助面板」实现；真实内容取自用户资料，演示模式明确标记。练习状态折叠讲解，以保证当前题目和反馈优先可见。

DeepSeek 协议参考：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)，查阅于 2026-11-24。Agent 和记忆的上游固定 commit 来源见 README 第二十节。仅借鉴适用的范围隔离、预算与恢复方法，不引入上游完整平台。

真实质量评测使用 `tests/evaluation/cases.json` 的八类案例；应在接通模型后逐项记录引用支持性、题目有效性、评分准确性、误记忆、调用次数与耗时。固定演示回复不可作为该评测的成功结果。

反馈回归新增目录同页边界、重复页眉、先修上下文、后台抢占/暂停、选项与理由复核及图片校验。Playwright 新增完整反馈流程，覆盖目录折叠、图片确认、选项/理由草稿恢复及手机布局。反馈文档只提供原教材截图，测试使用重建的原创同类 PDF，不能当作原教材逐页验收。

图片接口依据 [DeepSeek Vision 官方文档](https://api-docs.deepseek.com/guides/vision/)（2026-11-25 查阅），使用内联图片块，无需公开图片链接。
